# Memory Game

A browser-based matching game built with HTML, CSS, and vanilla JavaScript.

## How to Play

- Open two cards to find matching pairs.
- Find all eight pairs in as few moves as possible.
- Use **Restart** to start a new shuffled game.
- Use **Scores** to view the top 10 completed games.

The game tracks elapsed time and moves. Completed scores, including duration and date, are saved in the browser's `localStorage`.

## Run Locally

No installation or build step is required. Open `index.html` in a modern web browser.
